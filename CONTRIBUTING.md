**If you are a human: follow these:**

Despite `verbosum` being an AI tool, no AI code (including generated by `verbosum`!) will be accepted.

`verbosum` is meant to be used on code that you don't feel like writing. Code that you don't care about.
I don't want this project to have any code I don't care about. It's supposed to be a fun art project with
some learning about the state-of-the-art in AI on the side.

To that end, there isn't really a coding style guide. Use the opportunity to write code as a chance to
experiement with whatever Haskell ideas you wish! Kmett's "hammers looking for nails" comes to mind.
Make jokes and puns in the source code. Use whitespace to make it visually appealing.
